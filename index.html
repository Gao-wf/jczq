⚽ 竞足助手

示例数据
比赛：默认接 ESPN 真实赛程（无需注册、浏览器可跨域），显示当天真实足球比赛（英超/西甲/意甲/德甲/法甲/荷甲/葡超/英冠/比甲/欧冠/欧联/日职/中超 + 国家队：欧国联/世界杯/欧洲杯/国际友谊赛）。
注意：ESPN 免费接口不提供「韩K」「欧协联」，这两项仅在示例/演示模式下可见；真实模式选它们会提示无数据（后续接其他源再补）。
盘口：当前为示例盘口（标注“示例”）；真实 Bet365（36*）亚盘/大小球需付费赔率接口，到时再接。
每张比赛卡下方有 3 个预测比分框（可留空）和 实际比分框：第二天把真实结果填进「实际比分」，网页自动核对 3 个预测是否命中。
盘路颜色：红=赢盘 / 绿=输盘 / 灰=走盘（含赢半/输半）。
在「⚙ 数据源」可切换 ESPN / 示例 / API-Football；顶部「联赛」下拉可筛选，含「竞彩常用」「国家队」预设。

数据源设置

ESPN 真实赛程（默认·免注册）：直接拉取当天真实足球比赛（英超/西甲/意甲/德甲/法甲/荷甲/葡超/英冠/比甲/欧冠/欧联/日职/中超 + 国家队：欧国联/世界杯/欧洲杯/国际友谊赛），自动出赛果，彻底解决“不是今天比赛”的问题。无需账号、浏览器可跨域调用。
盘口说明：ESPN 提供的是赛程而非 Bet365 盘口，所以盘口目前仍显示示例盘口（标注“示例”）；要真实 36*(Bet365) 亚盘/大小球需付费赔率接口（如 API-Football 付费档），到时我再接。
韩K / 欧协联：ESPN 免费接口不提供这两项，仅演示模式可见；真实模式若选它们会提示无数据。
若手机/电脑离线或接口异常，会自动回退示例数据。
页面顶部「联赛」下拉可筛选指定联赛或预设（竞彩常用 / 国家队），选「全部联赛」显示所有比赛。筛选在真实赛程与示例数据下均生效。
